Ejercicios de autoevaluacion

Indique si cada uno de los siguientes enunciados es verdadero o falso. Si es falso explique por que.

  • a) Una lista ordenada no puede anidarse dentro de una lista desordenada
  • b) El elemento br representa un salto de linea
  • c) El elemento br representa un salto de linea
  • d) La anchura de todas las celdas de datos en una tabla debe ser igual
  • e) Estamos limitados a un maximo de cinco vinculos internos por pagina

Respuestas
  • a) Falso. Una lista ordenada puede anidarse dentro de una lista desordenada y viceversa
  • b) Verdadero
  • c) Falso. Los hipervinculos se denotan mediante elementos a.
  • d) Falso. Puede especificar la anchura de cualquier, ya sea en pixeles o como un porcentaje de la anchura de la tabla
  • e) Falso. Puede tener un numero ilimitado de vinculos internos

Complete la siguientes oraciones

  • a) El elemento ___ inserta una regla horizontal.
  • b) Para marcar un superindice se utiliza el elemento ___ y para marcar un subindice se utiliza el elemento ___.
  • c) El elementon de encabezado menos importante es ___ y el elemento de encabezado mas importante es ___.
  • d) El elemento ___ marca una lista desordenada.
  • e) El elemento ___ marca un parrafo.
  • f) El atributo ___ en un elemento input inserta un boton que, cuando se presiona, restablece el contenido del formulario.
  • g) El elemento ___ marca una fila de una tabla.
  • h) Los ___ se usan por lo general como caracteres de enmascarado de un cuadro de contrasela.

Respuestas
  • a) hr
  • b) sup, sub
  • c) h6, h1
  • d) ul
  • e) p
  • f) type = "reset"
  • g) tr
  • h) Asteriscos
